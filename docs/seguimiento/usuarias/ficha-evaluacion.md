# Ficha de evaluación con usuarias

Plantilla para la evaluación de T34 (prevista el 27/01/2027 en el entorno de pruebas). Para cada participante se copia este archivo como `U1.md`, `U2.md`, etc., y se rellena. No se registra el nombre ni ningún dato personal, solo la referencia.

## Cómo se desarrolla la sesión

1. Explico qué es Nudo en un par de frases y entrego las tareas por escrito.
2. La persona usa una cuenta de prueba de los negocios de ejemplo, desde mis dispositivos.
3. Mientras hace las tareas no intervengo salvo que se bloquee, y anoto la parte 1.
4. Al terminar responde el cuestionario de la parte 2 y comentamos lo que le ha costado más.
5. Cada problema observado se registra como incidencia (si es un error) o como propuesta de cambio (si es una mejora). Si una persona no completa sin ayuda una tarea de alumna, la incidencia tiene gravedad alta.
