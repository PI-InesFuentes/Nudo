# Evidencias

Aquí se guardan las capturas, informes y exportaciones que demuestran que una tarea, un indicador o un requisito se ha comprobado. Cada evidencia se enlaza desde el registro o la issue a la que corresponde.

## Nombre de los archivos

`IDENTIFICADOR_aaaa-mm-dd[_detalle].extensión`

| Ejemplo | Qué es |
|---|---|
| `IC-12_2027-01-27_lighthouse-reserva.pdf` | Informe de Lighthouse de la pantalla de reserva para el indicador IC-12. |
| `PR-05_2027-01-08.png` | Captura del rechazo de la sesión solapada del caso PR-05. |
| `T36_2027-02-01_cloud-run.png` | Captura de la aplicación publicada como evidencia de la tarea T36. |

No se guardan aquí datos personales ni contraseñas. Las capturas con datos de prueba usan solo las cuentas ficticias de los negocios de ejemplo.
